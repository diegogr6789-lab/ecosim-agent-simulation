# 📊 EcoSim: Python Economic & Population Multi-Agent Simulator

<img src="demo.gif" width="500" alt="EcoSim Gameplay Demo">

A dynamic simulation framework built with **Python** and **Pygame** that models complex economic systems, market mechanics (supply and demand), and autonomous agent decision-making.

## 🚀 Advanced Technical Features

- **Intelligent Multi-Agent System:** The population features distinct behavioral profiles (`Saver`, `Impulsive`, `Entrepreneur`). Every agent makes autonomous financial decisions based on capital balance, survival needs (hunger), and cost-benefit analysis.
- **Dynamic Supply & Demand Economy:** Marketplace prices dynamically self-regulate in real time based on the mathematical ratio between available item stock and local population volume.
- **Optimized Routing Algorithms:** Entrepreneur agents execute trigonometric distance calculations (`math.hypot`) combined with Lambda sorting keys to determine the optimal trade routes that maximize net profit margins.
- **Efficient Visual Rendering:** Features a clean UI with dynamic connection rendering (dashed lines), conditional text rendering for scales (automatic formatting to `K` and `M`), and highly optimized nested data structures.

## 🛠️ Tech Stack

- **Language:** Python 3
- **Graphics Engine:** Pygame
- **Mathematics:** Math, Random
